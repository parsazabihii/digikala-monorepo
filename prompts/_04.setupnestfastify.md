This is an empty Turborepo monorepo. First inspect it: package manager, turbo.json,
shared tsconfig, and which app is the backend (expected apps/backend). If unclear, stop and ask.

Set up a NestJS app in apps/backend using @nestjs/platform-fastify (not Express).

- Nest CLI with the SWC builder; TypeScript strict; experimentalDecorators and
  emitDecoratorMetadata on (Nest uses legacy decorators).
- Scripts dev, build, start, typecheck, lint, wired into turbo so they run from the root.
- main.ts: NestFactory.create with FastifyAdapter, listen on 0.0.0.0 and port 4000
  (hard-coded for now; config comes in a later step), enableShutdownHooks.
- AppModule with one HealthController: GET /health → { status: 'ok' }.
  Nothing else: no config module, no validation, no logging setup, no database.
